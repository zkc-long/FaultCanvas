# ADR 0001：以真实网络代理作为产品边界

- 状态：接受
- 日期：2026-09-15

## 背景

MoonBit 已有 MoonContract、MoonVCR 和 moonsim，分别覆盖规范 Mock、进程内录制回放和模型模拟。重复实现这些能力会降低生态价值和赛事可接受性。

## 决策

FaultCanvas 以独立 HTTP/1.1 反向代理为核心，将规则匹配和状态机作为纯逻辑库，将真实连接处理放入 native 适配层。

## 结果

项目可以测试任意语言客户端并执行真实网络故障，差异化清晰。代价是 native 网络层的测试和资源控制更复杂；通过协议范围、loopback 默认值和显式上限缓解。
